## 二、中危（1 项）

### 1. T0964 段3（修坛加持转移灾障）：「大白火星」被改写为「太白火星」

- **原文**：「若**大白**火星入於南斗」（大正藏 / CBETA 亦作「大白火星」，CBETA 于「大」字出校）。
- **译文**：正文作「若是**太白**火星进入南斗」；义解亦作「又特别举**太白**火星入南斗之例」。同一改动出现 2 处。
- **问题**：擅改原文用字（大→太），属与原文不符的误译/改字。（虽「太白」为金星之常名，但原文既作「大白火星」，译文应保留原文用字。）
- **修正建议**：正文改回「若是**大白**火星进入南斗」；义解同步改回。若确需说明，可在义解中另注「原文作『大白火星』，或即金星（太白）」——但**不得**径改原文字面。

## 三、低危

### T0964

1. **段1（净居天宫说法缘起）：「八部」增译为「天龙八部」**
   - 原文仅作「及諸四眾、**八部**、遊空大天……」，译文作「……四众弟子、**天龙八部**、游空大天……」。
   - 系增字（以「天龙八部」代「八部」）。于义无碍，仍属增译。
   - 建议：作「八部」（或「八部（即天龙八部）」，保留原文字面）。

2. **段3（修坛加持转移灾障）：正文内增插括注「（怨敌、灾祟）」**
   - 原文「畫彼設覩嚕形」；译文作「画出那设覩嚕**（怨敌、灾祟）**的形象」。
   - 设覩嚕（śatru）义为「怨敌」，「灾祟」为原文所无之增义，且正文夹注不宜。
   - 建议：正文只作「画出那设覩嚕（怨敌）的形象」，或径作「设覩嚕的形象」，释义移入义解。

3. **段7（建道场供养除灾）：改字与增字**
   - 原文「及男子女人**災詳**變禍」；译文作「以及男子女人**逢灾祥**变祸」。
   - 「詳→祥」为改字（原文用「詳」）；「逢」为增字。
   - 建议：作「以及男子女人灾详变祸」，或于义解中说明「詳」通「祥」。

4. **段9（闻法奉行九曜咒）义解：判归「流通分」欠妥**
   - 义解称此段（「九曜真言曰」之前）「此即经典的『流通分』」。
   - 但经文其后尚有大段「九曜真言」，流通分定性过早、与经文结构不尽相合。
   - 建议：改作「此段为闻法奉行部分，其后另有九曜真言附录」。

5. **段10 义解：术语对释精度不足**
   - 「曩谟三满跢没驮喃」释为「**归命一切正等觉者**」。原梵语 samanta-buddhānāṃ 义为「归命**一切诸佛**」，「正等觉者」为增义。
   - 「娑嚩贺」一律释为「**成就、圆满**」。svāhā 本为咒末感叹语，通行义解亦作「圆满成就」，然建议加注其为咒末收尾语，以免读者误认为实义词。
   - 建议：前者作「归命一切诸佛」；后者酌情作「娑嚩贺（svāhā，咒末收尾语）」。

6. **段4 / 段5 / 段8 / 段9：分段所致的技术性增符**
   - 如段4 咒文止于「……鉢囉（二合）」，译文于末**补加一「」」**（原文该处并无引号收束）；段5、段8、段9 在「娑嚩（二合）賀」/「薩婆訶」后插入「**（咒文照录）**」再补「」」。
   - 非义理错误，属断句/引用记号问题。
   - 建议：保持与原文标点一致，或统一以「（咒文照录，见下/上段）」形式处理，避免凭空增引号。

### T1677《三身梵讚》

> 本经通篇为梵语汉字音译赞颂。经程序逐字复核：**11 段梵音全部照录原文、无改字、无漏字**，正文亦**未对梵音作臆造义译**（各段均明示"照录原音"，释义一律置于【义解】）。下列问题均限于【义解】中的对音/释义。

7. **段2（梵赞句三至六）义解：「三摩」≈ samā，释作「平等、**等引**」牵强**
   - 「等引」为 samāhita（等引/等至，禅定术语）之意，非 samā（平等）之意。
   - 建议：只作「『三摩』近于 sama/samā，义为『平等』」。

8. **段8（梵赞句廿一至廿三）义解：「摩贺哩汤牟泥那」中释「哩湯」为 ṛṣi，对音较弱**
   - ṛṣi 之常译音为「哩史」「呬」等，「哩湯」对 ṛṣi 之音缺乏依据，属牵强对释。
   - 建议：保留「摩贺」（mahā）、「牟泥」（muni）之释，删去或加「姑存」以标明「哩湯」部分未能确指。

9. **段9（梵赞句廿四至廿六）义解：「奔女捺夜曩」释含 puṇya（福），对音较牵强**
   - puṇya 常译「布尼也/奔夜」，此处「奔女」对音较勉强。
   - 建议：改作「『捺夜曩』近于 puṇya（福）」，或标明存疑。

10. **段10（梵赞句廿七至廿九）义解：「钵啰拏莾」≈ praṇamāmi，所引字形不足**
    - 原文止于「鉢囉拏莾」，无 -māmi 之音；释为「我礼敬」宜降级为「近于 praṇama（礼敬）」。
    - 建议：作「『钵啰拏莾』近于 praṇama，义为『礼敬』」。

11. **段7 义解、段5 义解：义解引原音时用字与原音不一致**
    - 段7 义解引作「**三冒桃**」，原文作「**三冐桃**」；段5 义解引作「钵啰**室里**多」，原文作「鉢囉**室哩**多」（段8 义解亦作「**你**哩嚩拏」而原文作「**儞**哩嚩拏」）。
    - 引原音处应与原文字字一致，以免读者对不上原咒。
    - 建议：义解内引用原音一律照录原文用字。

12. **段5 段题 / 义解所述句次略有偏差**
    - 段题作「梵赞句十二至十四」，但段末「滿禰（引）」实属下句（十五）之首（原文：……具（引）爽（十四）滿禰（引）三菩誐哥（引）焬（十五））。
    - 建议：题/说明改为「第十二至第十四句（末含第十五句首『滿禰』）」。同类小疵：段11 题作「三十至卅三」，数字用「卅」，与它段「三十/廿」体例不统一，宜统一。

13. **段1（译题与梵赞首）义解：「三钵那」≈ saṃpanna 属推测性对音**
    - 该释已用「近于」，尚可；但同段对「莎波羅呬多」「陀囉部都」等未作交代，前后详略不一。
    - 建议：末句统一加「其余梵音未能确指，姑存原音」（段1 已有此语，可确保覆盖全部未释之音）。
