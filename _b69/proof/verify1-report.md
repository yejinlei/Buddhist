#### 2. 【严重 / 系统性】引号配对与嵌套错误

**问题性质**：第一轮修正试图处理跨段引文（原文引号在上一段未闭合、下一段继续）时，使用「外层『内层』交错」的方式处理，结果导致**每段开头多出孤立的 `「`/`』`，每段结尾缺失配对的闭合引号**，造成全经引号计数失衡（自动检测共发现 90+ 处单段内「」『』不配对）。

**典型模式**：
- 原文：一段以 `「……` 结束（未闭合），下一段以 `……」` 开头
- 修正后白话译文：每段开头孤立写 `」` 或 `『』` 或 `』』`，每段段末却不加闭合符，结果引号全乱
- 更严重的是：同一层语义中「」和『』交替使用，违反了「外层 `「」`、内层 `『』`」的嵌套规则

**具体错误示例**：

**(a) t0688 seg#佛赞问义**：白话开头出现两个连续闭引号 `』』`，为叠引号错误。
```
【佛赞问义】
』』
当时，世尊告诉阿难说：『善哉！……
```

**(b) t0878（全经普遍）**：每段开头几乎都有未配对的 `「` 或 `』`，例如 seg#五方佛礼：
```
【五方佛礼】
……
「南无常住三世清净微妙法身金刚界大悲毘卢遮那佛。
『南无金刚坚固自性身东方阿閦佛。
【义解】
```
——首句开 `「` 未闭合，第二句换用 `『` 开头，两段均未闭合，无结尾配对。

seg#总结圣众：
```
【总结圣众】
』
以上所说金刚界大曼荼罗三十七尊……
```
——开头凭空一个 `』` 闭引号，上一段并无对应的开引号。

**(c) t0698 seg#法会缘起→菩萨兴问**：
```
【法会缘起】…心中这样思惟：「诸佛如来是以什么因缘……呢？
【菩萨兴问】
』他又这样想：『各类众生……
```
——「未闭合，转段用』再开『，层次混乱。

**(d) t0861（密教仪轨，含真言跨段）**：seg#三昧耶印 结尾真言开 `「` 未闭合，seg#法界轮印 开头接 `诃（引）』` 错误闭合后再开 `『`，实为同一真言被错误断句并错换引号。同样问题见 seg#甲胄加持/奉请本尊、seg#奉献阏伽/敷座结界、seg#香食供印/灯明供印、seg#圆满供养/布字观身 多处。

**(e) t0915 seg#归命礼敬→礼佛真言→普供真言→灭罪归依…**：几乎每段都存在开头孤立 `』`、段内开 `「`/`『` 不闭合的问题。

**(f) t0938 seg#法器资格→佛德难思**：同样出现段首孤立 `』` 问题。

**(g) t0940 seg#译题序起→请法入岩**等：段首孤立 `』`，且 seg#法流通分 结尾出现 `』』` 重复闭引号。

**(h) t0940 seg#圣轮宝珠→种种圣物**：
```
【圣轮宝珠】
……作如是言：「若诸众生有所求事……皆令如意。」
【种种圣物】
』说完就为众生建立如意宝幢。
```
——前一段「」已闭合完整，下一段开头凭空多出 `』`。

**(i) t0688 seg#起疑生念→问佛功德→正陈所疑→佛赞问义**：连续四段开头/结尾出现孤立 `』`/`』』`，配对完全错乱。

**正确做法**：对于跨段连续引文（原文就是一逗到底跨多段），有两种可接受的处理方式：
- **方案 A（推荐）**：在白话译文中，将语义完整的引文在段末闭合；若必须分段，每段只保留语义内的引号，不要机械照搬原文「段末开着引号、段首闭引号」的古籍排版习惯（这种排版是因为古籍没有现代标点、跨段引号不重复前引号）。即：段内开 `「…`，段末应以 `…」` 闭合，下一段重新以白话叙述开始，不要在段首凭空放闭引号。
- **方案 B**：若严格保留跨段引文结构，则每段段末保持前引号开着、段首**不**添加闭引号，且整段引文必须使用同一对引号（外层 `「」` 到底），内层引语才使用 `『』`。

当前修正的错误在于：机械在段首放 `』`/`"，又在段内混用 `「` 和 `『`，导致引号层次混乱。

**涉及经号**：t0688、t0698、t0861、t0878、t0915、t0938、t0940 问题最严重；t0725、t0872、t0881、t0929、t0935 因原文为散文叙述、引文较少，引号问题相对较少，但并非完全没有（如 t0929 无 `「」` 引文，全部合格；t0935 全文未用 `「」`『』引号嵌套，合格）。
