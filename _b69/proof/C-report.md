## 分经问题清单

### t0688《佛说未曾有经》
- **【中0处 / 低1处】**
- **低1**：第[14]节"闻法欢喜"义解称"末尾所列「药王佛、药王菩萨、药上菩萨、最上天王佛」诸圣号，是抄写流传中附入的护持圣众名号"。原文四圣号紧接"诸比丘闻已，欢喜作礼"之后另行列名，确非经文主体；义解说"附入"为判断性表述，但原文未明言附入，此为考证性推断而非原文所无，不过"用以供读诵者礼敬忆念"属于推测，无原文依据，属轻微穿凿。

### t0698《浴佛功德经》
- **【中1处 / 低2处】**
- **中1**：第[7]节"法颂造像"白话译文将"若男子、女人、苾芻五眾應造佛像"译为"如果男子、女人、比丘、比丘尼等五众弟子应当造佛像"，义解将"五众"释为"比丘、比丘尼、式叉摩那、沙弥、沙弥尼"。按原文"男子、女人、苾芻五众"中"男子、女人"指在家男女，"苾芻"是出家人，此处"五众"不应仅指出家五众，原文"男子、女人"被译作"男子、女人"是对的，但义解将"五众"释为出家五众而排除了"男子、女人"（优婆塞、优婆夷），存在解释偏差。原文实际结构是"若男子、女人、苾芻五众"，即在家男女+出家五众共七众。义解范围有缩小。
- **低1**：第[10]节"颂明供养"白话译文将"獲得金剛身，具三十二相、八十隨形好"译为"获得金刚不坏之身，具足三十二相、八十种随形好"，其中"金刚身"解释为"金刚不坏法身"尚可，但原偈是赞供养者成佛后所得之身，义解直接说"金刚不坏法身"将"金刚身"限定为法身略有偏差，"金刚身"在佛典中也可指佛的坚固色身。
- **低2**：第[0]节义解称王舍城鹫峰山是"《法华经》《般若经》等大乘经典常说的说法道场"，其中"《法华经》《般若经》"说法的王舍城灵鹫山确为史实，但此段义解属常识补充，非原文内容，属于可接受的常识，但并非本经内容。

### t0725《佛说六道伽陀经》
- **【中1处 / 低2处】**
- **中1**：第[0]节"归敬启请"义解称"法天大师是北印度乌惹国人"，与原文译题"西天中印度摩伽陀国那烂陀寺三藏传教大师"直接矛盾。原文明确说法天是"中印度摩伽陀国那烂陀寺"的，义解说"北印度乌惹国"与原文不符。查法天本为中印度摩伽陀国人，后至乌仗那（北印度），但原题明确自署"中印度摩伽陀国"，译文义解改为"北印度乌惹国"属于失校，与原文标题直接矛盾。
- **低1**：第[3]节"号叫地狱"义解称"八热地狱依次为：等活、黑绳、众合、号叫、大号叫、炎热、极炎热、无间"，与原文叙述顺序不符。原文按颂次排列为：等活、黑绳、炎热、极炎热、众合、号叫、大号叫、无间（之后才是锋刃甲、铁叉树、剑叶林、铁丸、洋铜、铁轮等增狱）。义解套用了通用八热地狱顺序，而非本经实际叙述顺序，属于套话解释，但影响不大。
- **低2**：第[13]节"母驮药叉"义解将"母馱鬼"解释为"母驮鬼（摩怛哩、母陀鬼？即母鬼或人气势鬼）"，加问号显示不确定。原文"母馱鬼"对应梵语mātṛ（摩怛哩，母神/母鬼），义解加"？"不确定，不过因原文过简可以谅解，但应避免不确定臆测。

### t0861《毘卢遮那五字真言修习仪轨》
- **【中1处 / 低1处】**
- **中1**：第[13]节"布字观身"义解称"五字对应五大：阿字地大、尾字水大、啰字火大、吽字风大、欠字空大"，但这是对五字剑印真言"阿尾囉吽欠"的五大配属，而原文第[16]节月轮五字真实义是"「阿」字一切法本不生故；「尾」字思義一切法言說不可得故；「囉」字一切法離塵故；「訶」字一切法因不可得故；「佉」字一切如虛空不可得故"——即月轮五字是"阿、尾、啰、诃、佉"，不是"阿尾啰吽欠"。义解将护身五字（阿尾啰吽欠）与月轮五字（阿尾啰诃佉）的五大配属混为一谈，在讲月轮观的章节中解释五字五大时直接套用了"吽字风大、欠字空大"，但月轮第五字是"佉"（空大）而不是"欠"，第四字是"诃"（因不可得）而不是"吽"。这是把两套不同五字真言混为一谈的"想当然"错误。
- **低1**：第[14]节"持珠念诵"白话译文将"於頂中想白色「闇」字"译为"在头顶中观想白色「暗」字"，"闇"字是毘卢遮那的种子字，传统读音为"暗（aṃ）"，译文用"暗"代"闇"属于繁简转换问题，可接受；但第[16]节"「覽」字"译为"「览」字"同样简化，此为文字问题，非实质性错误。

### t0872《金刚顶瑜伽三十七尊出生义》

### t0878《金刚顶经金刚界大道场...礼忏文》
- **【中1处 / 低0处】**
- **中1**：第[12]节"总结圣众"白话译文将"普為五類：諸天世主、九際出世父母、諸善知識、道場施主、盡無餘界有情"译为"普为五类众生：一切诸天世主、历代出世父母、诸位善知识、道场施主、以及尽虚空界一切有情"。这里"九際出世父母"不是"历代出世父母"。"九际"指九种亲缘（九族：父四族、母三族、妻二族，合称九际/九族），"出世父母"指过去世父母。"九際出世父母"是指九族亲缘及过去世父母，不是"历代出世的父母"。"九际"被忽略，"出世"被译为"历代出世"有偏差。

### t0881《贤劫十六尊》
- **【中0处 / 低1处】**
- **低1**：第[7]节"初列天咒"白话译文将"門東多門天（金色），掌塔持寶棒"译为"东门旁多闻天（多门天）金色身，手托宝塔持宝棒"，将"多门天"直接等同"多闻天（毗沙门）"。原文为"多門天"，后面第[11]节有"招杜羅，毘沙門方"即毗沙门（多闻天）是第十二位招杜罗大将所对应的方位，并非"多门天"。"多门天"是外院另一天众（与毗沙门相关但非同一尊），译文直接注为"多闻天（多门天）"，将二者等同，属于混淆。不过考虑到原文简略、梵名相近，问题较轻。

### t0929《净瑠璃净土摽》
- **【中1处 / 低1处】**
- **中1**：第[12]节"结将灵鸟"白话译文将"此鳥諸上首五之所說法音悉同音惕說，故號共命鳥也"译为"这些鸟和诸位上首及五方佛的说法声音都相同，一同清晰演说妙法，所以又称共命鸟"。原文"諸上首五之所說法音"是指"诸上首（及）五（佛）"吗？仔细看原文"諸上首五之所說法音悉同音惕說"，"五之"应是"五（佛）之"的意思（即诸位上首与五佛所说法音），但原文断句也可解为"诸上首五尊之说法音"。更大问题是："迦陵頻伽、白鵠"在原文中是两种鸟（迦陵频伽鸟、白鹄），后面"此鳥"单数指"共命鸟"（Jīvajīvaka，即一身两头之共命鸟/命命鸟），原文明确说"故號共命鳥"，但前面列的是"迦陵頻伽、白鵠"两种鸟，最后"此鳥……故號共命鳥"指的是这两种鸟（或其中某一种？）。译文将"迦陵频伽、白鹄"与"共命鸟"混为一谈，说"这些鸟……所以又称共命鸟"，把三种鸟（迦陵频伽、白鹄、共命鸟）的关系说乱了。原文结构是："佛前内护作迦陵频伽、白鹄，此鸟诸上首五之所说法音悉同音惕说，故号共命鸟也"——即安置迦陵频伽、白鹄，这些鸟因能与佛说法同音、齐声说法，故总号"共命鸟"（或"命命鸟"指鸟声与佛声共鸣）。译文说"这些鸟和诸位上首及五方佛的说法声音都相同……所以又称共命鸟"，把"同音"解为"与佛音相同"而非"鸟自己同音（共鸣）"，存在理解偏差，且添加了"五方佛"原文未明示的解释。
- **低1**：第[10]节"四列二将"义解"涅哩底方（西北方？涅哩底为罗刹方即西南方）"，自身不确定。按佛教方位，涅哩底（Nairṛtī，罗刹方）确实是西南方，义解自我纠正为西南方是对的，但加问号显示不确定，属于注释不稳定。

### t0935《極樂願文》
- **【中0处 / 低1处】**
- **低1**：第[5]节"生生遇法"义解称"「七德庄严」通常指种姓高贵、身形端严、长寿无病、福报具足、正信坚固、善知识摄受、智慧明利七种修法的顺缘"。原文"高類七德"原文直译为"高类七德庄严"，义解列举七德为"种姓高贵、身形端严、长寿无病、福报具足、正信坚固、善知识摄受、智慧明利"，但这七项是义解自行组合，并非藏传"七德"（通常是种姓、色、力、寿、财、信、慧或其他）所确指。属于推测性补充，不过属常识范畴，问题轻微。

### t0938《釋迦文尼佛金剛一乘修行儀軌法品》
- **【中1处 / 低0处】**
- **中1**：第[13]节"甘露锡杖印"白话译文描述锡杖印结法为"先把右手大拇指横屈入掌心，用食指、无名指、小指紧紧握成拳头"，遗漏了"中指"。原文为"以頭指無名指小指急握作拳"——即大拇指横屈入掌，食指（頭指）、无名指、小指握成拳；原文未提中指的状态。但通常锡杖印（声闻锡杖印）的结法是"右手作拳，中指直竖为锡杖形"——白话译文说"食指、无名指、小指"握成拳，没有提到中指是竖直的还是握紧的，直接遗漏了中指的状态描述，读者无法完整还原印相。按密教手印规范，"頭指"（食指）、无名指、小指握拳，中指应直竖代表锡杖。白话译文将三指并列说"紧紧握成拳头"，会误导读者以为三指与大拇指一齐握拳，遗失了代表锡杖的直竖中指的关键信息。

### t0940《佛說帝釋巖祕密成就儀軌》
- **【中0处 / 低1处】**
- **低1**：第[3]节"请法入岩"义解称"十弓约五丈"（一弓五尺）。一弓的长度在不同时代不同，印度一弓（hasta）约为一肘半到两肘，中国古代"一弓为五尺"是唐制，可作为参考。义解给出具体数字，但原文无此换算，属考证性补充，可接受但属附加内容。

### 分级说明
- **高**：直接影响修行或产生重大事实错误（如把东面写成西面、左手写成右手、三字咒写成四字咒、十五种功德数成十四种、十六尊列成十五尊、种子字阿/闇/噁/唵混用、嚩/婆/婆嚩区别错误等）——本次校读未发现此类严重错误，白话在方位、手印、佛菩萨名号、种子字、功德数等核心事实上基本忠实原文。
- **中**：存在事实性偏差、概念混淆、印相描述关键信息遗漏、义解与原文直接矛盾（如法天出生地错误、"九際"误释、五字真言配属混淆、多门天与多闻天混淆、五众范围误释、鸟名混同、锡杖印遗漏中指等）。
- **低**：轻微表述偏差、推测性补充、注释不确定、文字转换问题、义解常识附加等。

### 核心优点
1. 梵文陀罗尼真言全部原样保留，二合、引声、反切音注、引、去声、切身、三合、四合等音注均照录未改；
2. 密教仪轨中手印、方位、种子字、五方佛、菩萨名、圣众数量（三十七尊、十六尊、十六执金刚、十二神将、二十天、八供养、四摄等）基本准确；
3. 专有名词首次出现多括注梵文或异名（薄伽梵、苾刍、由延、窣覩波、曼荼罗、阏伽、阿阇梨等）；
4. 古本校勘记、刊刻题记（延享、贞享、享和、长治、贞享三年等日本刊记）译文忠实，年代换算基本正确。

### 建议改进方向
1. 对密教手印的手指描述需逐字核对原文，不要遗漏任何一根手指的状态（如锡杖印的中指）；
2. 对梵文种子字配属需区分不同真言系统，避免将不同仪轨的五大配属混用（如阿尾啰吽欠vs阿尾啰诃佉）；
3. 对汉文典故词（如"九际"）需严谨训诂，不要望文生义；
4. 译者题款中明确写明的出生地、寺院等信息，义解不应另出新说与原文矛盾（如法天"中印度摩伽陀国"不应改为"北印度乌惹国"）；
5. 对带有"？""或云"等不确定表述的原文，义解尽量先存疑再考定，不要在无把握时下断语。
