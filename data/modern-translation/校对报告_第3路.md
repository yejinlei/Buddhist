# 佛经白话译文校对问题列表（第3路）
## 问题条目
1. **经号：t1151**
   - 段号：7、8
   - 问题描述：金刚缚真言「嚩日囉（二合）滿馱」被错误拆分，前半「嚩日囉（二合）」留存于段7咒文末尾，后半「滿馱」错置于段8【义解】标签之后，成为义解正文开头，导致咒文不完整、位置错误。
   - 修正建议：将段8开头的「滿馱」移至段7的咒文末尾，合并为完整咒文「嚩日囉（二合）滿馱」，段8义解正文从「保持之前的金刚缚印，在胸前心口处掣击...」开始。
2. **经号：t1173**
   - 段号：12
   - 问题描述：结地界印的译文中残留了翻译草稿自问自答内容：「（无名指）插入力度（食指）与愿度（小指）之间，戒度（中指）插入慧度（大拇指）与力度之间？不对，十度对应十指：檀那（施）-小指、尸罗（戒）-无名指？不对，这里直接复述结法即可：按仪轨十指交插...」，属于非正式翻译内容混入正式译文。
   - 修正建议：删除草稿疑问与备注内容，直接翻译结法为：「结法：将忍度插入力度与愿度之间，戒度插入慧度与力度之间，以愿度从手背方向插入进度与忍度之间，方便度插入檀度与戒度之间，檀、慧、进、力、禅、智各指指尖相拄，手印向下覆，禅智二指拄地如同钉橛，诵陀罗尼三遍；观想手印如同独股金刚杵，带火焰杵直彻金刚地基。」
3. **经号：t1187**
   - 段号：24
   - 问题描述：「通達聲聞緣覺所有諸法」被错译为「通达声闻、缘所有诸法」，漏译「覺」字，导致「缘觉」（辟支佛）术语错误。
   - 修正建议：改为「通达声闻、缘觉所有诸法」。
4. **经号：t1234**
   - 段号：5、6
   - 问题描述：降魔初咒「怛𭔞他（引）護嚕護嚕贊拏（引）禮摩（引）鄧詣娑嚩（二合引）賀」被错误拆分，前半留存于段5咒文末尾，结尾「賀」错置于段6【义解】标签之后，导致咒文不完整。
   - 修正建议：将段6开头的「賀」移至段5咒文末尾，补全完整咒文为「怛𭔞他（引）護嚕護嚕贊拏（引）禮摩（引）鄧詣娑嚩（二合引）賀」，段6义解从「无能胜菩萨说此明时，变身为天女像...」开始。
   - 段号：7-30
   - 问题描述：根本长陀罗尼、护生陀罗尼共24段咒文全部漏录，仅标注「此段为根本陀罗尼咒文...一律照录原文」但未实际粘贴咒文内容，属于严重的咒文缺漏。
   - 修正建议：严格对照original_preview内容，逐字补录所有陀罗尼咒文，完整保留梵字、反切、二合/三合标注，不得用说明性文字替代咒文原文。
5. **经号：t1245**
   - 段号：16-28
   - 问题描述：鸠盘拏众、诸大龙王、羯吒布怛曩众、药叉大将、罗刹众等段落中，原文列有大量鬼神、龙王专有名称，译文仅保留前2个名字，其余用「等众多」「等一众眷属」随意概括省略，属于名号漏译。
   - 修正建议：完整照录原文中所有梵语音译的鬼神、龙王名称，不得用「等」字省略专有名号。
