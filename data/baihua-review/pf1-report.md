# 《佛垂般涅槃略说教诫经》《受五戒八戒文》白话译文校对报告

**校对对象**：pf1.md（fo_yijiao《佛垂般涅槃略说教诫经》21 段 + t0916《受五戒八戒文》11 段，原文·译文逐段对照）
**校对方法**：把各段白话译文与原文逐句比对，并核校原文本（T0916 依《大正藏》第 18 册 No.0916；fo_yijiao 依《佛遗教经》通行本）。核查范围：忠实性（漏译/增译/曲解）、术语、法数、有无杜撰、标点与体例。
**声明**：本次只作校对，未改动任何译文与原文；下表"修改建议"仅供后续修订参考，不构成重译。

## 二、中危问题

| 经号-段号 | 问题级别 | 具体问题 | 修改建议 |
|---|---|---|---|
| fo_yijiao-第20段 | 中危 | 原文"何有智者得除灭之，如杀怨贼而不欢喜！"中，"如杀怨贼"是修饰前面的"得除灭之"（除灭此身=如杀怨贼），"而不欢喜"才是全句的反问谓语。译文"哪有智者除掉灭它，会像杀掉怨贼一样不欢喜呢！"把"像杀掉怨贼一样"直接接到"不欢喜"上，等于说"像杀怨贼那样地不高兴"，比喻对象错位，句意容易被读反。 | 改为："哪有智者能除灭它时，不像除掉怨贼那样欢喜呢！"（保住"如杀怨贼"修饰"除灭"的原结构。） |
| t0916-第7段 | 中危 | 原文作"趣寂聲聞漏悲菩薩"（诸本一致）。"漏悲菩萨"词义不明，译文却径直写成"留（大悲不证实际）的菩萨"，把"漏"当"留"讲，属推测性改读，且未出校记说明依据。 | 正文保留原词作"漏悲菩萨"，并加注："原文作'漏悲'，或系'悲增'之异文/形误，指以大悲留惑润生、不证实际之菩萨"。不要在无提示的情况下改字。 |

## 三、低危问题

| 经号-段号 | 问题级别 | 具体问题 | 修改建议 |
|---|---|---|---|
| fo_yijiao-第5段 | 低危 | 原文"不令纵逸犯人苗稼"之"犯"为侵害、践踏义；译文"不让它放纵侵犯罪了别人的庄稼"中的"犯罪"误读原义，句子也不通顺。 | 改为"不让它放纵，去侵害（践踏）别人的庄稼"。 |
| fo_yijiao-第3段 | 低危 | 原文"戒是正顺解脱之本"，"正顺解脱"意为"正顺（于）解脱"。译文"戒是随顺正法、趣向解脱的根本"把它拆成"随顺正法"＋"趣向解脱"两层，并无端增出"正法"，属增字解经。 | 改为"戒是正顺解脱的根本"或"戒是（令人）正顺解脱的根本"，不必增"正法"。 |
| fo_yijiao-第1、3段 | 低危 | 同一术语"波罗提木叉"夹注前后不一：第1段注"（戒律）"，第3段注"（别解脱）"。波罗提木叉（prātimokṣa）本义为"别解脱／别别解脱"，注作"戒律"较宽泛。 | 前后统一，如均作"波罗提木叉（别解脱，通指戒律）"。 |
| fo_yijiao-第1段（义解） | 低危 | 段标签作【序分·嘱托重戒】，同段义解却称"本段是正宗分的开端"，对同一段的判位自相矛盾（该段前半"释迦牟尼佛初转法轮…略说法要"为序分，后半"汝等比丘，于我灭后…"才是正宗分起）。 | 义解改为"本段前半为序分，后半自'汝等比丘，于我灭后…'起为正宗分之开端"。 |
| fo_yijiao-第15段（义解） | 低危 | 义解列举"全经诸门"作"戒、定、慧、少欲、知足、远离、精进、不忘念、禅定、智慧、不戏论"，其中"定"与"禅定"、"慧"与"智慧"重复，且漏列本经实有的"制五根""制心"两门。 | 改为"持戒、制五根、制心、少欲、知足、远离、精进、不忘念、禅定、智慧、不戏论"。 |
| fo_yijiao 全篇 ／ t0916 第4、10段 | 低危 | 标点与体例：fo_yijiao 原文直引号成对性有误（第1段开引号未闭；第4段作"…之所住处。"\"汝等比丘…"；第16段作"…众无疑故。"前多出引号；第21段段首多一引号），且原文用""而译文统一用「」，体例不一。t0916 第4、10段原文段首各残留一个孤立的"。"。 | 原文引号尽量成对，或与译文统一为「」；删去段首残留的孤立句号。 |
| fo_yijiao 全篇 | 低危 | 与《佛遗教经》通行本比对，本材料 21 段为节选，缺"受诸饮食当如服药""昼则勤心（睡眠、惭愧）""若有人来节节支解（忍辱）""当自摸头（憍慢）""谄曲之心与道相违（质直）"五节。 | 若本意为全经白话，需补足上述五节的原文与译文；若确为节本，建议在文件开头注明"节本"，以免读者误当全译。 |
| t0916-第2/3段 | 低危 | 分段与原典分品不符：原文"梵曰懺摩此云悔過，從今已後斷相續心，往昔罪愆總願消滅"在《大正藏》本中属〈第二洗懺往業品〉（即本材料第2段）之末，文件却把它移入第3段（〈得戒三歸品〉／【归依三宝】）之前，致段首出现与本段主题不合的"忏悔名义"句。 | 将"梵曰懺摩…總願消滅"移回第2段之末，或相应调整第2、3段的分段与标签。 |
| t0916-第4/5段、第10/11段 | 低危 | 分段错位：原文"能持否"本为各品（〈問持說品〉、〈說相合修章〉）的末句，文件却分别把它移置到第5段、第11段之首，使逐段对照错位。 | 将"能持否？"归入第4段、第10段之末（与该句所属之品一致）。 |
| t0916-第5、11段 | 低危 | 原文仅有"能持否"，译文作"能持否？（能持。）"，"（能持。）"系据仪轨补出，属增译。 | 正文不加；如确需体现受者应答，改用译注形式，如"能持否——（受者应答：能持）"。 |
| t0916-第8段 | 低危 | 原文"五旃陀羅"，译文注作"五位旃陀罗（刽子手）"。旃陀罗（caṇḍāla）佛典常译"屠者、贱民、执暴恶人"；"刽子手"仅系其职事之一，如此夹注易使读者把此譬喻误读为"五个行刑人"。 | 改注为"五位旃陀罗（屠者／贱民，caṇḍāla）"。 |
| t0916-第4段（义解） | 低危 | 义解"前五即五戒之化身口（不饮酒肉）"语句不通（"之化身口"费解）；又"后三为斋支"与通说（八关斋戒为"七戒一支"，第八"不非时食"为斋）不合。 | 前句改为"前五即五戒（不杀、不盗、不染欲、不妄语、不饮酒食肉）"；后句改为"第六、七、八为斋支，其中'过中食'一支即斋"。 |
| t0916-第11段（义解） | 低危 | 义解称"「髻中宝」「衣里珠」用《法华》《楞严》之典"。"髻中明珠"（《法华经·安乐行品》）与"衣里珠"（《法华经·五百弟子受记品》衣珠喻）均出《法华》，云出《楞严》无据。 | 改为"用《法华经》髻珠喻、衣珠喻之典"。 |
| t0916-第4段 | 低危 | 原文"七不作倡伎樂故往觀聽"意为"（不）自作倡伎（歌舞）乐，（亦不）故意前往观听"；译文"七不作倡伎乐及故意前往观听"未显出否定，易被读成"要去观听"。 | 改为"七不作倡伎（歌舞）乐，也不故意前往观听"。 |
| t0916-第7段 | 低危 | 原文"是我等輩真善知識，醫王大師攝受我故"，"医王大师摄受我故"意为"因（其）是医王大师、摄受我们的缘故"；译文"……如医王大师摄受我故"增出"如"字，且"……摄受我故"半文半白，句意不畅。 | 改为"是我等的真善知识，因是医王大师、摄受我们的缘故"。 |
| t0916-第1段 | 低危 | 原文"乘形紀身成正覺者"费解，译文以"乘形化身成就正觉的诸佛"译之，属推测性改读，未出注。 | 正文可作"乘形纪身（或谓'乘形记身'）成正觉者"，并加注存疑，勿径改为"化身"。 |

## 四、总评

本次核对的两部译文整体忠实、通顺：**法数层面无一处错漏**（八戒八条、五戒五条、三归、四流"见·欲·有·无明"、五盖、十缠、三有等均与原文一一对应），亦未发现杜撰原文所无的内容，术语（波罗提木叉、优婆塞戒、八关斋戒、三有、四流、五盖十缠、四毒蛇六入空聚等）基本准确。存在的问题以**低危的用词／句式与体例项**为主，其中 t0916 第7段"'漏悲'径改为'留'"、fo_yijiao 第20段"如杀怨贼"比喻错位两处建议优先修订；另两点需提请注意——一是 t0916 若干段的起讫（"能持否""梵曰懺摩…"）与原典分品不一致，逐段对照时易生错位；二是 fo_yijiao 原文实为节本（缺五节），如目标是全经白话需补足。以上均不改动译文原意，仅供后续修订取舍。
