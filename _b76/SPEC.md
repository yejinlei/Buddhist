工作根目录：`/home/user/workspace/13511660557912876654/buddhist-ontology`

## 任务
对分配给你的每一部经，读取切段骨架 JSON，为每一段填 `modern`（白话译文），
生成完整译文 JSON 写入 `data/modern-translation/<经号>.json`。

- 输入骨架：`data/baihua-tasks/<经号>.json`
  （顶层 7 字段：id / title / translator / mode / intro / sutraPath / translations；
   每段 3 字段：section / original_preview / modern；骨架里 modern 为空串）
- 输出译文：`data/modern-translation/<经号>.json`（完全相同的结构，只把 modern 填好）

## 红线（不可违反）
1. **`original_preview` 一律逐字照抄骨架，一个字都不许改动**（含标点、异体字、音注括注、
   全角空格）。只写 `modern`，不改其它任何字段。`translations` 的段数与顺序与骨架完全一致。
2. **不编造**：不增补原文没有的内容。存疑处如实说明（如「疑『X』之讹」），不改原文用字。
   失译经只记「失译」；疑伪经须标注「疑伪」；阙文标「（阙）」，不臆补。
3. JSON 必须合法：字符串值内**禁止出现未转义的英文直引号 `"`**；引用一律用「」『』。
   写完用 `python3 -c "import json;json.load(open('路径'))"` 自检。

## `modern` 体例（每段，三条硬性要求）
- 必须以 `【` 开头（第一个字符是【）；
- 必须**包含** `【义解】`；
- **不能以 `【义解】` 结尾**（义解后面必须还有白话正文）。
- 推荐格式：`【小标题】【义解】……白话解释……`[再补校勘/名相/背景说明]
- `【小标题】`用概括本段内容的中文短语，如「【经题译者·总标经义】」「【二乘与佛乘·校量】」。
- `【义解】`后先给白话解释（把古文译成通顺现代汉语），再就名相、背景、异译、校勘作简要说明。

## 语言体例
- 白话一律**简体**；标点一律**全角**；禁用半角引号（`"` `'`）。
- 专名音译用字按原文保留，不作繁简转换（如「乾闼婆」之「乾」、「毘」等）。

## 咒文/真言/偈颂处理
- 咒文（真言、陀罗尼）**一律照录原文用字**，不作义译、不转简体；
  须在「【义解】」中说明「咒文照录原文用字与音注，不改一字」。
- 白话叙述中若引用经文原语，用「」标出并保留原字。
- 偈颂：逐句或逐段译其义，可在义解中提示「四言/五言/七言偈」。

## intro 字段
- `intro` 写 1–3 句导语：经名、卷数、译者/作者（按骨架，失译即记「失译」）、
  主要内容与性质（疑伪经须标注「疑伪」）。`translator` 字段维持骨架原值不动。
