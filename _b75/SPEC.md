# 第75批 白话精译规范（worker 必读）

## 任务
对指定经号，读取切段骨架 JSON，为每一段填 `modern`（白话译文），
生成完整译文 JSON 写入 `data/modern-translation/<经号>.json`。

- 输入骨架：`data/baihua-tasks/<经号>.json`（顶层 id/title/translator/mode/intro/sutraPath/translations）
- 输出译文：`data/modern-translation/<经号>.json`（同结构，`modern` 填好）
- 工作根目录：`/home/user/workspace/13511660557912876654/buddhist-ontology`

## 红线（不可违反）
1. **`original_preview` 一律逐字照抄骨架，一个字都不许改动**（含标点、异体字、音注括注）。
   交付前用非空白字符逐段比对，必须完全一致。
2. 只写 `modern`，不改其它任何字段。`translations` 段数与顺序与骨架完全一致。
3. **不编造**：不增补原文没有的内容。存疑处如实说明（如「疑『X』之讹」），不改原文用字。
4. JSON 必须合法：字符串值内**禁止出现未转义的英文直引号 `"`**；引用一律用「」『』。
   写完用 `python3 -c "import json;json.load(open(路径))"` 自检。

## `modern` 体例（每段）
- 格式：`【小标题】【义解】……白话解释……`，可再接补充说明。
- 必须以 `【` 开头（第一个字符是【），必须**包含** `【义解】`，且**不能以 `【义解】` 结尾**。
- `【小标题】`用概括本段内容的中文短语，如「【经题译者·总标咒义】」「【地狱名号·第一】」。
- `【义解】`后先给白话解释（把古文译成通顺现代汉语），再可就名相、背景、异译、校勘作简要说明。
- 白话一律**简体**；全角标点；专名音译用字按原文保留。

## 咒文/真言/偈颂处理
- 咒文（真言、陀罗尼）**一律照录原文用字**，不作义译，不用简体转写；
  需在「【义解】」中说明「咒文照录原文用字与音注，不改一字」。
- 白话叙述中若引用经文原语，用「」标出并保留原字。
- 偈颂：逐句或逐段译其义，可在义解中提示「四言/五言/七言偈」。

## intro 字段
- `intro` 写 1–3 句导语：经名、卷数、译者/作者（按骨架，失译即记「失译」）、
  主要内容与性质（如疑伪经须标注「疑伪」）。`translator` 字段维持骨架原值不动。

- 完成后回报：每个经号的段数、是否通过 JSON 自检、是否逐字比对 preview 通过。
